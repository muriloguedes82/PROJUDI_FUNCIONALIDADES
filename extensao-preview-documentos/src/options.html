Envio de documentos por e-mail (Outlook)

"Outlook Web (sem Azure AD)" abre o outlook.office.com de verdade num pop-up, o usuário faz login normalmente, e a extensão tenta anexar os documentos automaticamente assim que a tela de novo e-mail aparece. É mais simples de configurar, mas é uma automação não-oficial que pode parar de funcionar se a Microsoft mudar a interface do Outlook Web — nesse caso, anexe os documentos manualmente.

Microsoft Graph (opcional, necessário só para o modo Graph)
